# Guide du wizard : aiguillage

Ce document ne décrit plus le wizard d'optimisation : sa description complète vit désormais dans **[la page du wizard avancé](docs/wizard-avance.md)**.

Le menu principal du produit, lui, garde son arborescence réelle :

```text
1. RECHERCHE D'OBJETS
2. LISTE DES EQUIPEMENTS
3. LISTE DES PANOPLIES

4. OPTIMISATION DE STUFF
5. SYSTEME
```

Tapez `4` puis **Entrée** pour ouvrir l'optimisation.

Toutes les pages de la documentation sont listées dans le [sommaire de la documentation](docs/sommaire.md).
