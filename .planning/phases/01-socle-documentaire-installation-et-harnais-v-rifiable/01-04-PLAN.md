## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Documentation -> lecteur | La page est la surface suivie aveuglement : une option inventee ou une adresse fausse y est recopiee dans un terminal. |
| Test -> produit | L'ancrage interroge le parseur du produit ; toute introspection privee ou toute execution franchirait une frontiere non autorisee (D-14, D-15). |

| Page -> code produit | Les libelles ecran et le message d'erreur cites par la page sont produits par `routes.py` et `sync.py` : un renommage dans le code rendrait la page fausse sans qu'aucun lien ne soit mort. |
