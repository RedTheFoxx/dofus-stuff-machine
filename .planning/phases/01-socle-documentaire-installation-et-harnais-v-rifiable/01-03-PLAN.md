## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Arbre de documentation -> harnais | Les pages sont lues puis comparees ; toute lecture non stricte ou toute ecriture reviendrait a modifier la source de verite depuis un test. |
| Harnais -> arbre livre | Le test de mutation ecrit : s'il ecrivait dans `docs/`, il corromprait le depot ; s'il ecrivait sous `.data/`, il detruirait la base de developpement. |
| Lecteur -> page mal rattachee | Une page dont le H1 diverge de son libelle d'index rend l'index trompeur sans qu'aucun lien ne soit mort. |
