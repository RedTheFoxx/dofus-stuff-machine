## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Documentation -> lecteur | Un exemple marque est une commande que le lecteur recopie : s'il est faux, incomplet ou destructeur, le degat est immediat sur sa machine. |
| Page -> base locale `.data/dofus.sqlite3` | La page nomme la commande qui vide la base ; cette commande ne doit jamais apparaitre comme une commande a recopier, et aucun test ne doit l'executer. |
| Test -> produit | L'ancrage n'utilise que le parseur public ; toute execution ou toute introspection privee franchirait la frontiere interdite (D-14, D-15). |
| Harnais -> arbre de documentation livre | Les derives de preuve de morsure vivent dans une copie jetable ; l'arbre livre doit rester intact pour que la suite garde sa valeur de signal (lecon WR-05). |
| Texte de page -> controle | Une regle evaluee par section laisserait echapper l'entete de page : la garde destructrice et la regle d'exemple portent sur le texte entier, ligne a ligne (lecon WR-02). |
